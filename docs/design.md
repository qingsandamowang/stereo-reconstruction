# 双目视差与三维重建设计

日期：2026-09-23

## 目标与来源

使用 ETH3D 官方低分辨率双目训练集及对应真值，完成可评估的双目匹配、深度计算和点云重建。该项目与硕士阶段“双目结构光和三维重建”综述相关，但不宣称采集过自己的双目数据或实现结构光投影。原计划的 Middlebury 官方下载在当前网络环境超时，因此改用同样具有标定与真值的 ETH3D 官方数据。

## 方法

读取左右图、PFM 视差真值、非遮挡掩码及标定文件。使用 OpenCV StereoBM 作为基线，StereoSGBM 作为主要方法，并增加左右一致性和无效视差过滤。只在预留验证场景上选择参数；在不参与调参的场景上计算有效覆盖率、端点平均误差（EPE）及 Bad 2px 比例。按标定关系将视差变为深度并导出带颜色的 PLY 点云，同时保留视差图、误差热图与运行配置。

## 边界

基线是传统双目算法的工程实现和评估，不声称发明新模型。测试指标必须注明分辨率、非遮挡掩码及有效覆盖率。深度单位以数据标定为准，不能在未核实标定格式前假定单位。

## 核验

PFM 读取、标定解析、视差误差和深度公式有针对性测试；实际运行完整官方训练场景中的验证/测试划分，保存数字报告和可查看的点云文件。简历仅引用真实报告中的可解释结果。
